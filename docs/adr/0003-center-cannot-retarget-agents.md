# ADR-0003. Цели и учётные данные хранятся только у агента

Статус: заменено ADR-0006.

## Контекст

Спецификация описывает Connection Registry в Control Plane. Если центр хранит адреса и пароли, его взлом открывает доступ ко всем БД всех арендаторов.

## Решение

- Список источников и учётные данные лежат в локальной конфигурации агента.
- Агент сообщает `source_key`, движок, версию и возможности. Центр выдаёт `source_id`.
- Задания ссылаются на `source_id`. Адреса в заданиях нет.

## Последствия

- Добавление источника требует изменения конфигурации агента, а не клика в интерфейсе. Для заказчиков с жёсткими требованиями это плюс, для удобства минус.
- Центр не может проверить подключение сам, только через агента.
- Изменение границы доверия согласовано при утверждении плана.
